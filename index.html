강릉시 아파트 거래 대시보드

매매, 전세, 월세 실거래와 단지 위치, 기간별 흐름을 한 화면에서 확인하는 강릉시 부동산 전망 분석 화면입니다.

GitHub Pages 공개용

최종 공개 인덱스

이 페이지는 GitHub에서 바로 열리도록 만든 안내용 첫 화면입니다. 실제 자동 조회, 지도 표시, 단지 선택, 일간/주간/월간/년간 집계는 사용자 PC의 로컬 실행파일과 서버에서 작동합니다.

데이터 기준 공공데이터 국토교통부 실거래 API 기반
지도 기준 VWorld 주소 좌표 및 위치 확인
분석 단위 강릉시 동, 단지, 거래유형별 비교
화면 상태 바로 표시 GitHub Pages에서 깨지지 않는 정적 화면
핵심 기능

대시보드에서 확인하는 분석

기간별 거래 흐름

일간, 주간, 월간, 년간 기준으로 매매, 전세, 월세 거래량과 가격 흐름을 비교합니다.

선택 단지 분석

아파트를 선택하면 주소, 최근 실거래, 비교 단지, Top 10 순위를 함께 확인합니다.

입지 경쟁력

역세권, 학군/학교권, 주민센터, 상권 접근성을 지도 반경과 거리로 표시합니다.

시장 전망

거래 증감, 가격 변화, 매매 비중, 리스크 신호를 조합해 강릉시 전망을 요약합니다.

거래 달력

연월을 선택해 날짜별 거래 건수를 빠르게 확인하고 특정 시점의 집중도를 살핍니다.

공식 데이터 우선

자동수집은 공식 API와 다운로드 가능한 데이터 중심으로 연결하고, 출처와 기준월을 구분합니다.

월별 흐름 예시

매매 · 전세 · 월세 거래량 비교

실행 방법

실제 데이터 조회는 로컬에서 실행

1

파일 받기

GitHub 저장소 파일을 내려받거나 기존 로컬 프로젝트 폴더를 엽니다.

2

실행파일 클릭

강릉시_아파트_대시보드_배포용.exe 또는 실행 배치파일을 클릭합니다.

3

브라우저 확인

로컬 서버가 켜지면 http://localhost:5177/에서 최종 대시보드를 확인합니다.

GitHub 저장소 열기 배포 페이지 열기
중요 안내

공개 페이지와 로컬 대시보드의 차이

API키 보호

공개 GitHub Pages에는 공공데이터포털, VWorld API키를 넣지 않습니다.

서버 기능

실거래 자동수집과 좌표 변환은 로컬 서버의 server.js에서 실행됩니다.

배포 안정성

이 인덱스는 외부 API 호출 없이 즉시 표시되므로 GitHub Pages에서 빈 화면이 되지 않습니다.

출처: 공공데이터포털, VWorld, 국토교통부 실거래 공개자료. 공개 페이지는 안내용이며, 최종 분석값은 로컬 실행 대시보드에서 확인합니다.
