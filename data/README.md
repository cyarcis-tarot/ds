# 강릉시 부동산 대시보드 데이터 설명

이 폴더는 대시보드가 쓰는 데이터를 모아 둔 곳입니다.
쉽게 말하면, `data` 폴더는 대시보드의 "재료 창고"입니다.

## 한눈에 보기

1. `raw/` 폴더에는 처음 받은 원본 파일을 그대로 넣었습니다.
2. `market-indicators.csv`, `economic-indicators.csv`는 대시보드가 읽기 쉽게 다시 정리한 표입니다.
3. 대시보드는 이 정리표를 읽어서 미분양, 입주량, 가구소득, 경제 흐름을 화면에 보여줍니다.
4. API 키가 들어 있는 `.env`, `.env.local`은 비밀 열쇠라서 GitHub에 올리지 않습니다.

## 대시보드가 직접 읽는 정리표

### `market-indicators.csv`

부동산 시장을 판단할 때 필요한 숫자를 모은 표입니다.

- `year`: 몇 년 자료인지 적는 칸입니다.
- `unsoldUnits`: 아직 팔리지 않은 집, 즉 미분양 주택 수입니다.
- `moveInUnits`: 앞으로 새로 입주할 아파트 물량입니다.
- `householdIncome`: 강릉시 가구소득입니다. 현재 `4,173만원`이 입력되어 있습니다.
- `mortgageRate`: 대출금리 같은 금융 지표를 넣을 수 있는 칸입니다.
- `source`: 이 숫자를 어디서 가져왔는지 적는 칸입니다.

대시보드에서는 이 파일을 보고 다음을 계산합니다.

- 공급/미분양: 미분양이 많으면 집값에는 부담이 될 수 있습니다.
- PIR/부담: 집값이 소득에 비해 비싼지 보는 데 사용합니다.
- 1~5년 전망: 입주량과 미분양을 함께 보고 상승/조정 가능성을 판단합니다.

### `economic-indicators.csv`

강릉시 경제가 좋아지는지, 약해지는지 보기 위한 표입니다.

- 산업단지 고용: 일자리가 늘었는지 봅니다.
- 아파트 거래량: 집 거래가 활발한지 봅니다.
- 방문자 수: 관광과 생활 상권에 도움이 되는 흐름입니다.
- 인구와 청년 인구: 실제 살 사람과 미래 수요를 보는 데 중요합니다.
- 강릉역 하차 이용객: 교통 이용과 외부 유입을 보는 지표입니다.

대시보드에서는 이 파일을 `선택 아파트 1~5년 전망` 설명에 같이 사용합니다.
예를 들어 방문자와 고용이 늘면 좋은 점으로 보고, 인구와 청년층이 줄면 조심해야 할 점으로 봅니다.

## 원본 파일 보관함

`raw/` 폴더에는 원본 자료를 그대로 넣었습니다.
이 파일들은 "처음 받은 증거 자료"입니다.

- `2025년 강릉시 사회조사(통계표).xlsx`
  - 강릉시 가구소득을 확인하는 데 사용했습니다.
- `16 소득 및 지출(2025).xlsx`
  - 소득과 지출 관련 참고 자료입니다.
- `260831_입주예정물량_공개용.xlsx`
  - 앞으로 입주할 아파트 물량을 확인하는 데 사용했습니다.
- `미분양주택현황(2026년7월말)_통계누리.xlsx`
  - 강릉시 미분양 주택 수를 확인하는 데 사용했습니다.
- `강릉시 경제지표 동향 브리프(2024년 하반기).pdf`
  - 고용, 방문자, 인구, 강릉역 이용객 같은 경제 흐름을 확인하는 데 사용했습니다.

## 지금 입력된 핵심 숫자

- 강릉시 가구소득: `4,173만원`
- 미분양: `1,311호`
- 2026년 입주예정 물량: `1,882호`
- 산업단지 고용: `2,185명`
- 2024년 하반기 방문자: `2,609만명`
- 강릉시 총인구: `211,566명`

## 앞으로 데이터를 추가할 때

1. 원본 파일은 `data/raw/`에 넣습니다.
2. 대시보드가 바로 읽어야 하는 숫자는 CSV 파일로 정리합니다.
3. 새 CSV를 만들면 README에 "무슨 자료인지" 쉽게 설명합니다.
4. API 키나 비밀번호는 절대 올리지 않습니다.
