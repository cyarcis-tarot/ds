# 강릉시 부동산 대시보드 데이터

이 폴더는 교수님이 GitHub에서 결과물을 확인할 수 있도록 대시보드에 사용한 공개/첨부 데이터를 정리한 공간입니다.

## 가공 데이터

- `market-indicators.csv`: 대시보드가 직접 읽는 시장 보조지표입니다.
  - `unsoldUnits`: 강릉시 미분양 주택 수
  - `moveInUnits`: 강릉시 입주예정 물량
  - `householdIncome`: 강릉시 가구소득 환산값
  - `source`: 원자료 출처 설명

## 원본 데이터

`raw/` 폴더에는 사용자가 제공한 원본 엑셀 파일을 그대로 보관합니다.

- `2025년 강릉시 사회조사(통계표).xlsx`
- `16 소득 및 지출(2025).xlsx`
- `260831_입주예정물량_공개용.xlsx`
- `미분양주택현황(2026년7월말)_통계누리.xlsx`

API 키가 들어 있는 `.env`, `.env.local` 파일은 보안상 GitHub에 올리지 않습니다.
